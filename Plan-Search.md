## Результаты выполнения

### Реализованные файлы и компоненты

| Файл | Описание |
|------|----------|
| `frontend/index.html` | Форма поиска, блок «Проверить гостиницу», карточки отелей, кнопка «Мой выбор (N)» в шапке |
| `frontend/my-choice.html` | Страница выбранных отелей: карточки, дата выбора, «Убрать из выбора», «Скачать карточку», «Вернуться к поиску» |
| `frontend/js/app.js` | Логика Alpine.js: autocomplete городов/отелей, `displayHotels`, `sortHotels`, `myChoices`, `toggleMyChoice`, `loadMyChoices` / `saveMyChoices` |
| `frontend/js/hotel-card.js` | `hotelToMarkdown()`, `downloadHotelCard()` — формирование и скачивание .md без зависимостей |
| `frontend/css/style.css` | Стили карточек, `.hotel-highlights` (приоритет цены и оценки), `.message-info`, `.btn-download-card` |

### Логика «Мой выбор»

- **Хранение:** `localStorage` ключ `mybesthotel_my_choice`, формат `[{ hotel: {...}, selectedAt: "ISO date" }]`
- **Кнопка в шапке:** «Мой выбор (N)» — счётчик выбранных отелей, ведёт на `my-choice.html`
- **Пустой список:** сообщение «У вас нет выбранных отелей», кнопка «Вернуться к поиску»
- **Изоляция:** my-choice.html использует только `config.js`, `hotel-card.js` и inline-скрипт с `myChoiceApp()` — без app.js

### Иконка «Мой выбор»

- SVG-иконка закладки (зелёные оттенки) перед текстом «Мой выбор» в шапке формы поиска
- Форма: петелька сверху + тело ленты с вырезом «ласточкин хвост» (равнобедренный треугольник)

### Скачивание карточки в .md

- Кнопка «Скачать карточку» во всех карточках: результаты поиска, результат проверки, страница «Мой выбор»
- Имя файла: `{id}-{название}.md` (например, `hotel_022-Hostal-Veracruz.md`)
